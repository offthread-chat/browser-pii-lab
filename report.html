01 Compare by input length

Latency is median complete-request time. Input tokens include special tokens repeated at chunk boundaries. First chunk completion is not a streamed token or an emitted partial result. p95 is shown only with at least 20 runs; 100K has one run per model.

02 Memory over the longest run

OS RSS summed across the isolated Chrome processes, sampled about every 250 ms. Includes browser/runtime overhead and duplicated shared pages; not model-exclusive memory. Sizes run in increasing order without resetting the worker, so GC and earlier allocations affect later baselines. Lines have different durations.

03 First result from a fresh browser

Includes weight download, initialization and detection of the short workload. Fresh browser context caches were empty, but network/CDN/OS caches were not controlled. These single observations are not a cold-start ranking.

04 Read the evidence

All inputs repeat one synthetic English template. Long inputs are split into many BERT-sized chunks; none of these models has a 100K context window. Resource polling adds overhead. Other apps, thermal state and model execution order can affect results. Short-request CPU includes a larger fraction of sampling overhead. Memory is not reset between lengths.
